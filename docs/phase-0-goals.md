# Phase 0: 프로젝트 설정 및 설계

## 목표
- 프로젝트의 기본 구조를 설정하고, 핵심 도메인에 대한 초기 설계를 진행한다.

## 작업 목록
1.  **디렉토리 구조 생성**: `src/` 와 `tests/` 디렉토리를 생성하여 소스 코드와 테스트 코드를 분리한다.
2.  **의존성 설정**: `pyproject.toml` 파일을 생성하고 `fastapi`, `uvicorn`, `sqlalchemy`, `psycopg2`, `pytest` 등 초기 의존성을 정의한다.
3.  **핵심 도메인 정의**: `Snippet` 애그리거트 루트의 핵심 속성을 브레인스토밍하고 문서화한다.
